<li>
<p style="line-height: 1;"><span style="font-size: 14pt;">Гарантийный ремонт распространяется только на неисправности, возникшие в результате произведённого ремонта.</span></p>
</li>
<li style="line-height: 1; font-size: 14pt;">
<p><span style="font-size: 14pt;">Гарантия устанавливается на каждый товар или услугу отдельно.</span></p>
</li>
<li style="line-height: 1; font-size: 14pt;">
<p><span style="font-size: 14pt;">Гарантийный ремонт не распространяется на аксессуары поставляемые с оборудованием.</span></p>
</li>
<li style="line-height: 1; font-size: 14pt;">
<p><span style="font-size: 14pt;">Сервисный центр может отказать в гарантийном ремонте в следующих случаях:</span></p>
<ul class="tiptap-bullet-list">
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">неправильно заполненных документов;</span></p>
</li>
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">нарушения сохранности гарантийных пломб;</span></p>
</li>
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">использования оборудования вместе с аксессуарами, не одобренных предприятием изготовителя;</span></p>
</li>
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">повреждений вызванных нарушением условий эксплуатации и хранения;</span></p>
</li>
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">несанкционированного вмешательства;</span></p>
</li>
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">наличия механических, химических или тепловых воздействий;</span></p>
</li>
<li style="font-size: 14pt;">
<p><span style="font-size: 14pt;">стихийными бедствиями, водой;</span></p>
</li>
</ul>
</li>
<li style="line-height: 1; font-size: 14pt;">
